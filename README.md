# AMUP Interactive AI Board

ക്ലാസ്സ്‌റൂമിനുള്ള മലയാളം ഇന്ററാക്ടീവ് വൈറ്റ്ബോർഡ്. Android ഫോണിലോ ടാബിലോ Chrome-ൽ തുറന്ന് പ്രൊജക്ടറിലേക്ക് മിറർ ചെയ്ത് ഉപയോഗിക്കാം.

## ഉള്ളത്
- പേന (സൈസ് മാറ്റാം), ഹൈലൈറ്റർ, ഇറേസർ
- ഷേപ്പുകൾ: ചതുരം, വൃത്തം, ത്രികോണം, വര, അമ്പ്, നക്ഷത്രം (തിരഞ്ഞെടുത്ത് വലിച്ചാൽ വരും)
- മലയാളം ടെക്സ്റ്റ്, പേജുകൾ, Undo/Redo, നാലുവര കോപ്പി / ഗ്രിഡ് / കറുത്ത ബോർഡ് പശ്ചാത്തലം
- ✨ വാക്ക് എഴുതി വട്ടമിട്ടാൽ ചിത്രം: എഴുത്ത് വായിച്ച് വിക്കിപീഡിയ / Wikimedia Commons ചിത്രങ്ങൾ കാണിക്കും; ബോർഡിൽ വെച്ച് വലുതാക്കാം, ചെറുതാക്കാം, നീക്കാം
- PNG ആയി സേവ് ചെയ്യാം; ബോർഡ് ഫോണിൽ തന്നെ സേവ് ആയിരിക്കും

## സൗജന്യ സേവനങ്ങൾ മാത്രം
- കൈയെഴുത്ത് വായിക്കൽ: Google Input Tools handwriting (key വേണ്ട)
- ചിത്രങ്ങൾ: Wikipedia, Wikimedia Commons API (key വേണ്ട)
- ഹോസ്റ്റിങ്: GitHub Pages

ഇവ രണ്ടിനും ഇന്റർനെറ്റ് വേണം. ഇന്റർനെറ്റ് ഇല്ലെങ്കിലും ബോർഡും ഉള്ളിലുള്ള ചെറിയ ചിത്ര ലൈബ്രറിയും പ്രവർത്തിക്കും.

## Android-ൽ ആപ്പ് പോലെ
Chrome-ൽ സൈറ്റ് തുറന്ന് മെനു → "Add to Home screen". പിന്നെ ഫുൾസ്ക്രീനിൽ തുറക്കും.
